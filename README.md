# 💰 MyBank – A Simple Banking App

A beginner-friendly web app that simulates basic banking operations like deposits, withdrawals, and transaction tracking.

## 🔧 Features
- Create a virtual account
- View and update balance
- Deposit and withdraw money
- Track transaction history

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- LocalStorage (optional for data persistence)

## 🚀 How to Run
1. Clone the repo
2. Open `index.html` in your browser
3. Start banking!

## 🌟 Future Enhancements
- Login system
- Budget tracker
- AI-powered saving tips
- Backend with Flask or Node.js
